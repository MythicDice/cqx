## 标签候选

解析器按以下优先级识别方括号：

1. 正文转义 `\[`、`\\`；
2. 完整的合法结束标记 `[/name]`；
3. 完整的 `[@identifier]`；
4. 以 `[:` 开始的通用标记；
5. 名称属于固定简写表、且后接结构空白、`]` 或 `/` 的短标签；
6. 其余字符按正文保存。

`identifier` 满足 `[A-Za-z0-9_.-]+`。`[@all]` 专指全体成员；要提及 ID 字面值 `all`，写 `[:at id="all"/]`。

被识别的标签候选若格式或结构错误，严格解析器必须报错。例如 `[img]` 是缺少 `src` 的已识别短标签，`[note]` 则是普通文本：

```text
这是普通文字：[note]、[1,2,3]、a&b、<x>。
```

## 名称

元素名满足 `[A-Za-z][A-Za-z0-9_.-]*`，属性名满足 `[A-Za-z_][A-Za-z0-9_.-]*`。名称区分大小写，内置元素名全部为小写 ASCII。扩展元素推荐使用带命名空间的通用名称，例如 `org.example.poll`、`acme.card`。

只有本草案登记的简写名称可以省略 `:`。未知元素使用 `[:name ...]` 形式；解析器必须保留其名称、属性、原子或容器模式及子内容。

## 固定简写表

v0.2 的简写名称为：

| 类别 | 名称 |
| --- | --- |
| 原子 | `[@identifier]`、`img`、`reply`、`face`、`audio`、`video`、`file`、`ref` |
| 容器 | `b`、`i`、`code`、`link`、`forward`、`msg` |
| 原样形式 | `[code raw]...[/code]` |

简写表在版本内固定。新增简写需要新的语法版本；扩展元素不得自行注册新的 v0.2 简写名称。

## 原子与容器写法

通用原子元素以 `/]` 结束，通用容器元素以相同名称的 `[/name]` 结束：

```text
[:img src="cat.png"/]
[:b]重要[/b]
```

空容器 `[:x][/x]` 与原子元素 `[:x/]` 是两种不同的数据结构。容器元素可以嵌套。

简写一律以 `]` 结束。常见原子元素可以省略 `/`：

```text
[img cat.png]
[audio voice.ogg]
[file report.pdf]
```

**原子简写中的尾随 `/` 属于位置参数内容**，因此常见 URL 可以直接粘贴：

```text
[img https://example.org/a/]
```

上例对应 `src="https://example.org/a/"`。通用写法中的 `/]` 仍是语法终止符，最后一个裸属性值若以 `/` 结尾，应使用引号保留该字符：

```text
[:img src="https://example.org/a/"/]
```

容器简写不能自闭合。`[b/]` 中的 `/` 会被读成位置参数并报错，必须写出 `[b]...[/b]`。

## 属性

属性写作 `name=value`，多个属性之间使用结构空白分隔。属性名和 `=`、`=` 和属性值之间不允许空格。属性名在同一元素内必须唯一，属性顺序不影响消息语义。

```text
[:img src=cat.png alt="一只猫"/]
[file report.pdf name="年度报告.pdf"]
```

属性值在词法层全部为字符串。`id=00123` 保存为 `"00123"`，`active=true` 保存为 `"true"`；解析器不执行数值或布尔转换。

属性值有两种形式：

| 形式 | 规则 |
| --- | --- |
| 裸值 | 非空，可含字母、数字、冒号、斜线、问号、`&`、`=`、`#`、逗号、点号；不得含结构空白及 `[`、`]`、`"`、`\` |
| 引号值 | 双引号包围的 JSON 字符串，支持 `\"`、`\\`、`\n`、`\t`、`\uXXXX` 等转义 |

`=` 在属性值内部合法，以下输入无需加引号：

```text
[img https://example.org/a.png?size=2&format=webp]
[:link href=https://example.org/?q=cat&page=2]猫[/link]
```

需要写空字符串时使用 `""`。内置元素的必需标识符或地址不得为空；扩展元素可以使用空字符串属性。

## 位置参数

下列简写允许省略一个常用属性名：

| 简写 | 对应属性 | 示例 |
| --- | --- | --- |
| `img` | `src` | `[img cat.png]` |
| `audio` | `src` | `[audio voice.ogg]` |
| `video` | `src` | `[video clip.mp4]` |
| `file` | `src` | `[file report.pdf]` |
| `reply` | `id` | `[reply 42]` |
| `face` | `id` | `[face 14]` |
| `ref` | `id` | `[ref 42]` |
| `link` | `href` | `[link https://example.org]网页[/link]` |

每个简写最多一个位置参数；`link` 是唯一支持位置参数的容器简写。位置参数与同名的命名属性同时出现时必须报错。通用写法只允许命名属性。

**命名属性优先规则**：一个未加引号的 token 从起始位置满足 `合法属性名=` 时，解析为命名属性；其他合法 token 可以是位置参数。

```text
[img src=https://example.org/?x=1]
[img https://example.org/?x=1]
[img "foo=bar"]
```

第一行写入 `src` 命名属性，第二行把 URL 作为 `src` 位置参数，第三行把 `foo=bar` 作为 `src` 的字面值。因此 `[img foo=bar]` 缺少 `src`，严格解析器报错。

> **注意**
>
> CQX 没有注释语法。行尾的 `# ...` 会成为正文文本。

## 结构空白

标签识别、属性分隔以及 `forward` 排版空白共用固定集合：

| 字符 | 码点 |
| --- | --- |
| 水平制表符 HT | U+0009 |
| 换行 LF | U+000A |
| 回车 CR | U+000D |
| 空格 SP | U+0020 |

U+00A0 等其他 Unicode 空白不参与标签起始识别。例如 `[img cat.png]` 中间使用 U+00A0 时，整段作为普通文本保留。
