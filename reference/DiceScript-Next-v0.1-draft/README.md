# DiceScript Next — v0.1 语言设计草案

> **独立设计讨论稿 / 非 SeaDice 官方规范 / 尚无解释器。** 版本：`0.1-draft`，整理日期：2026-11-07。
> 本项目暂称 **DiceScript Next**；文件扩展名 `.rdl` 仅供草案示例使用，**不代表已确定名称、扩展名或兼容性承诺**。

## 一句话定位

面向 TRPG 的**中间层脚本语言**：拥有 DiceScript 级别的领域能力，比通用 JavaScript 轻；复杂扩展继续交给 JS。**无类与继承体系、类型标注可选、表达式优先、对象优先、错误可诊断。**

## 十个已采用的草案约定

1. `x := expr` 声明，`x = expr` 赋值；未声明的名字不能直接赋值。`x: Int := expr` 可选类型标注。
2. 基本数据统一为值/对象；以 `{ 名称: 值, 方法(参数) { ... } }` 组织数据与行为，**不提供 `class`、继承或原型链**。
3. 不提供 `say`/`print`/`echo`。执行块以最后一个表达式的值返回；宿主将**非空可渲染返回值**插入原文。
4. 普通骰点使用 `d20`、`3d6kh2`；CoC/Fate/WoD/DX 等避免词法冲突的规则使用 `r"b2"`、`r"f"`、`r"5a9k2"` 等。
5. `Roll` 是**已经执行过的一次随机计算**；访问变量或字段不会重新掷骰。
6. `Formula` 是**延迟执行的公式**：`formula(ctx => ...)`，调用 `.eval(ctx)` 才执行；普通字段访问不触发计算。
7. 读取/修改普通变量、对象属性、数组元素没有未声明的隐藏副作用；对象方法当然可以显式修改状态。
8. 语言级 `Bool` 独立于 `Int`，条件必须是 `Bool`；`0` 和 `false` 均可正常渲染，`null`、`Unit`、空字符串不渲染。
9. 有受限运行语义、可序列化语言值/函数/公式、静态诊断；不将工具链或解释器的存在误写为已实现。
10. **能力覆盖 ≠ 源码语法兼容**。旧语法与新语义的差异参见 `docs/07-dicescript-coverage.md`。

## 入门速览（假想的合法程序）

```text
actor := { 侦查: 75 }            # 演示；实际 actor 可由宿主注入

检定(技能) {
    骰 := d100
    if 骰 <= 技能 {
        `成功（{骰.total}）`
    } else {
        `失败（{骰.total}）`
    }
}

检定(actor.侦查)                # 最后表达式成为结果
```

外部文本中的执行块：

```text
调查员进行侦查：{{ 检定(actor.侦查) }}
```
