# DiceScript Next · 语言核心规范 v0.1（草案）

**状态**：设计规范，非可运行产品。凡使用“必须/应”表达的是 v0.1 的**设计承诺**，而非软件现状。未覆盖或未决部分在 `docs/08-open-questions.md` 标明。

## 1. 定位与边界

本语言用于 TRPG 命令中的骰点、角色卡属性公式、可序列化的规则逻辑、可插入文本的模板，以及少量控制流。复杂事件、网络、异步、大型插件与应用编程交由 JavaScript。语言自身不暴露网络/文件系统/进程 API，也不设计类继承体系。

三项必要的领域对象：

- **Object**：字段、方法及状态的组合；不要求 class/prototype/interface。
- **Roll**：一次已完成的随机计算，保留最终值和结构化过程；读取不再抽取随机数。
- **Formula**：显式可重复执行的公式；读取返回公式本身，`.eval()` 才执行。

## 2. 核心语法

```text
x := 10                       # 声明、推断 Int
x = 11                        # 重新赋值
x: Int := 10                  # 可选类型注解
s := String(123)              # 显式转换

加值(n) { n + 2 }              # 命名函数，推断返回类型
双倍 := n => n * 2            # 匿名函数

r := {                        # 无类对象
    HP: 12,
    受伤(n) {
        self.HP = max(0, self.HP - n)
        self.HP
    },
}
r.受伤(3)
```

语句可按换行或分号分隔，**并非 JavaScript 自动分号插入**；括号内以及明显未结束的运算表达式可换行。每段代码的最后一个表达式提供该段的值；声明和赋值本身结果为 `Unit`。`if` 是表达式，`while` 是返回 `Unit` 的语句。

最小保留关键字：`if`、`else`、`while`、`break`、`continue`、`return`；`true`、`false`、`null` 是字面量，`self` 是方法中的特殊绑定。`formula`、`roll`、`Int` 等均为内建对象/函数名，不是关键字。

## 3. 值、类型与转换

内建类型：`Int`（有符号 64 位）、`Float`（有限 IEEE-754 binary64）、`Bool`、`String`、`Null`、`Unit`、`List`、`Object`、`Function`、`Roll`、`Formula`；宿主可以注入 `NativeObject` 等具有声明接口的类型。

普通变量在声明时从表达式推断类型；推断不清楚的参数/宿主属性按 `Any` 作动态验证；类型标注并非使用语言的前提。**推断得到的局部变量类型是约束，不是每次赋值都随意变化的提示**；需要动态类型时可写 `x: Any := ...`。

- `Int`/`Float` 算术按数值提升规则处理，字符串不自动转数字。
- `Int(value)`、`Float(value)`、`String(value)`、`Bool(value)` 为显式转换；失败报错。
- `if`/`while` 条件与 `&&`/`||` 操作数必须是 `Bool`；`&&`/`||` 短路并返回 `Bool`。
- `??` 只在左侧为 `null` 时计算并取右侧；可写 `x: Int? := null`。
- `Roll` 在定义好的数值运算、比较中可以按 `.total` 参与，但保留轨迹；显式 `Int(roll)` 或 `Float(roll)` 才丢弃轨迹。

## 4. 作用域与函数

作用域采用词法规则。`{...}` 控制流块内声明仅在该块有效；对外层已有变量赋值会修改该绑定。函数形成闭包，返回最后一个表达式的值，允许 `return` 提前退出。命名函数可递归；对象方法通过 `self` 访问接收者；提取方法值后也保留接收者绑定。**没有 `this` 动态环境、`class`、继承、原型链、方法可见性关键字**。

## 5. 骰点

普通：`d20`、`3d6`、`2d20kh1`、`4d6dl1`、`d20优势`、`(n + 1)d(20)`。大多数规则简写采用 `r"..."`，例如 `r"b2"`、`r"p1"`、`r"f"`、`r"5a9k2"`、`r"4c3m7"`。动态字符串用 `roll("...")`，受宿主的规则注册与预算约束。

`Roll.total` 给最终数值；`Roll.faces` 是数值骰面列表；`Roll.dice` 是带轮次、保留状态等元数据的骰面记录；`Roll.trace` 为结构化计算树；`Roll.detail` 为按宿主显示风格生成的文本。`Roll + 2` 仍为 Roll；`Int(roll)` 丢弃轨迹；多次读取同一变量不会重新抽取随机数。详见 `docs/03-dice-and-formula.md`。

## 6. 延迟公式

```text
伤害 := formula(ctx => 2d6 + ctx.力量)
角色 := { 力量: 4, 伤害: 伤害 }
角色.伤害                # Formula 对象，不执行
角色.伤害.eval(角色)      # 执行，可能得到 Roll
角色.伤害.eval(角色)      # 再次执行，新的独立样本
```

公式只能读取输入、使用可序列化值及执行计算/骰点，不能修改宿主状态或捕获对象；公式与普通函数都可按约定序列化。对 formula 的 `.bind({...})` 产生带默认参数的新 Formula，`.eval(ctx)` 中提供的属性覆盖绑定的默认参数。

## 7. 对象与集合

`{ 字段: 值, 方法(参数) { ... } }` 为普通对象；键必须是 `String`，允许 `obj.key` 和 `obj["key"]` 访问，均不会隐式求值。未知字段读取报错；要为缺失键提供默认值使用 `obj.get("key", default)`。对象可变更已有键，也可增加键；静态已知对象的疑似拼写错误会给出诊断。

列表支持字面量、`[1..5]` 闭区间、`[value] * n` 重复、切片 `[start:end]`（右边界不包含）、切片赋值、`sum/kh/kl/shuffle/len/rand/randSize/push/pop/shift`，以及 `map/filter/count`。无隐式字符串↔数字键转换。

## 8. 文本与宿主接口

脚本没有输出关键字。宿主在文本 `{{ code }}` 位置执行代码，并将其最终值转换为文字插回原位。`null`、`Unit`、`""` 产生空替换；`0`、`false` 必须显示；错误进入诊断通道，**不可被当成空结果吞掉**。反引号模板串使用 `{expr}` 插值，普通单双引号不插值。自定义对象可声明无副作用的 `to_text()`。

宿主可注入 `actor`、`state` 和骰点规则对象；这些名字只是注入变量，不是语言关键字。限额包括指令数、递归深度、骰数、骰面、爆骰轮次、内存、字符串长度和序列化大小；随机源可注入并种子复现。可选的“骰点纯表达式模式”禁止修改和流程控制，但不改变同一段合法表达式的解释结果。

## 9. 静态错误、兼容性及未决问题

未声明变量、语法错、函数形参数量错、静态可见的属性拼写错、明显不合法的骰点后缀及错误类型运算，都应带有位置和修复建议。旧 DiceScript 的 `&(expr)` computed、`loadRaw*`、全局无声明赋值、特殊规则标识符/宏不按原样继承；**映射其能力而非复制其隐式语义**。
