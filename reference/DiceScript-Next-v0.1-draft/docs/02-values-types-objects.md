# 02 · 值、类型、对象与函数

## 类型与推断

类型系统为**轻量渐进检查**，而不是完整的静态通用语言类型系统。无需标注即可写完整脚本。对于初始化有明确值的局部绑定，分析器推断并约束其类型；形参、动态对象和宿主数据可以是 `Any`，并在运行时检查操作。

```text
hp := 12                # Int
标题 := "探索"
骰 := d20               # Roll
列表 := [1, 2, 3]
变化: Any := 12          # 允许之后换成其他类型
变化 = "未知"
可空值: Int? := null
可空值 = 8
```

`hp = "12"` 为已知类型错误；`hp = Int("12")` 合法。若类型被推断为 `Any`，检查器不能声称它已被证明安全。

- `Int`: 有符号 64 位整数，溢出报错。
- `Float`: 有限 IEEE-754 binary64；产生非有限数时报错。
- `Bool`: `true` / `false`，不是 `Int` 的别名。`if 1 {}` 错，`if Bool(1) {}` 对。
- `String`: Unicode 字符串；字符串下标/切片以 Unicode 标量值计数（非字节）。
- `Null`: `null`，仅用于缺失、可空值。
- `Unit`: 无结果，不能当 `Null` 使用。赋值、声明、`while` 返回 `Unit`。
- `List`: 可变有序集合；默认允许混合元素，分析器仅检查能确定的用法。
- `Object`: 字符串键到字段/方法的可变映射，支持对象组合，不存在类及继承。
- `Function`: 有词法环境的可调用值。
- `Roll`: 已结算骰点，数值 + 计算过程。
- `Formula`: 延迟计算，显式 `.eval()`。

`Any` 只用于类型检查上的动态边界，不是能屏蔽运行时错误的万能值。

## 数字及逻辑

`Int + Float` 提升为 `Float`，`Int / Int` 也得到 `Float`；`%` 限 Int；`**`/`^` 为乘方。整数与浮点在安全、可解释范围内比较；不自动把数字转字符串。`Int("12")` 解析十进制；`Int(3.9)` 向零截断；`Float("3.5")` 解析有限值；`Bool(0)` / `Bool(null)` / `Bool("")` 为 false，非零数字、非空字符串与非空集合为 true，空集合为 false；对未知自定义对象执行 `Bool(obj)` 默认 true，若宿主不允许则报错（仍需明确转换）。

条件和逻辑运算**不隐式应用** `Bool`。`&&`/`||` 短路并返回布尔值，`??` 只识别 `null` 而不是所有假值；三元表达式的条件要求 Bool。

## 对象而非类

```text
角色 := {
    名称: "战士",
    HP: 12,
    护甲: 2,
    受伤(n) {
        self.HP = max(0, self.HP - max(0, n - self.护甲))
        self.HP
    },
}

角色.受伤(5)
角色["HP"]
角色.职业 = "战士"                # 允许动态添加键
```

语义规定：

1. 每次求值 `{...}` 都构造一个新的对象身份；对象赋值/传参传递引用，普通数字/字符串按值语义。
2. `obj.a` 与 `obj["a"]` 是同一字段读取；不存在 `__proto__`、隐藏父类查找或 getter 自动求值。
3. 未定义字段读取**报诊断/运行错误**；`obj.get("a", default)` 是获得缺失默认值的方式。`obj.has("a")` 返回 Bool。
4. 显式 `obj.a = ...` 可覆盖/添加字段；对于静态已知形状的对象，疑似误拼写的新字段发出警告。
5. 对象方法是对象自有的函数成员；`self` 在方法调用时绑定到接收者。`f := obj.m` 将接收者绑定在可调用值中；`f()` 仍针对 `obj`。
6. 对象中的普通函数值（如 `f: x => x+1`）**不会**因为读写字段而自动变成方法；只有 `m(args) { ... }` 方法成员获得 `self` 绑定。这样避免调用语义随存放位置变化。
7. 没有继承、接口声明、原型、操作符重载入口或类方法元编程。内建对象行为由语言定义，不开放任意用户定义的运算符协议。

## 函数、闭包与返回

```text
倍率 := 3
加成 := n => n * 倍率
加成(5)                # 15

阶乘(n: Int) -> Int {
    if n <= 1 { 1 } else { n * 阶乘(n - 1) }
}
```

每次函数调用创建独立的局部词法绑定；外部变量可由闭包捕获。`return expr` 提前结束函数。方法和函数在未显式返回时返回最后一个表达式的值。命名函数可自递归；`break`/`continue` 只影响最近循环。

## 作用域、赋值与状态

```text
x := 1
if true {
    y := 2
    x = 3
}
x                     # 3
y                     # 错误：不在作用域
```

不可使用 `x = 1` 自动创建局部变量。声明不能覆盖同层已有绑定；内层同名遮蔽允许但应提示警告。状态持久化依靠宿主注入的 `state` 对象（`state["键"] = ...`），而不是内建的隐式全局写入。

## 列表与切片

`[1..5]` 是包含两个端点的区间（反向范围 `[5..1]` 同样支持）；`a[i:j]` 是半开切片；列表下标从零开始。非法索引报错，`a[i:j] = values` 可替换一段连续元素。`[x] * n` 创建重复列表，对可变对象元素复制**引用**而不是深拷贝，避免与对象身份规则冲突。

`.shuffle()` 不修改原数组并返回新排列；`.randSize(n)` 不放回抽样；`.push(v)` 在原数组尾部追加并返回原数组以支持链式；`.pop()`/`.shift()` 修改原数组并返回被移除的值。

切片中的负索引支持从尾部计数，超出合法边界报错；字符串切片按 Unicode 标量值，而非 UTF-8 字节索引。`sum`、`kh`、`kl` 等操作对可比较数值与 Roll 值工作，Roll 值会保留计算过程。
