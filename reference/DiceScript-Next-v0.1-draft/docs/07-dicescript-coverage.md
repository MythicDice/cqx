# 07 · DiceScript 能力覆盖矩阵

**来源**：2026-11-07 核对的 SeaDice DiceScript 官方 `README.md`、`docs/GUIDE.md`。本表是**语言设计的目标映射**，不是已完成的功能清单，也不表示官方背书或老脚本零改动兼容。

| DiceScript 中的能力 / 习惯 | v0.1 的能力映射 | 兼容性说明 |
|---|---|---|
| `d20` / `3d6` / 动态 XdY | 相同基础骰语法，产出 Roll | 取值承载形式改变 |
| `k/kh, q/kl, dl, dh, min, max` | 同名规范化骰点修饰，明确执行顺序 | 无效组合会报错，不依赖历史歧义 |
| `d20优势` / `d20劣势` | 保留简写 | 固定等效语义 |
| CoC `b/p` | `r"b2"` / `r"p1"`、`coc.bonus/penalty` | **非裸词法兼容** |
| Fate `f` | `r"f"` / `fate.roll()` | 非裸词法兼容 |
| WoD `XaYmZkNqM` | `r"..."` / 规则对象 | 非裸词法兼容，尊重具体规则参数 |
| Double Cross `XcYmZ` | `r"4c3m7"` 或 `roll(string)` | 非裸词法兼容；对象 API 参数签名待定 |
| 自定义骰点解析 | 在独立规则骰文法中注册 | 不影响普通标识符解析 |
| Int / Float / String / Null | 同等基本值、显式转换 | 新增 Bool 与 Unit；避免假值混用 |
| 数组 / `[..]` / `[x] * n` | List、闭区间、重复 | 保留用法，行为细节以新规范为准 |
| 数组切片与切片赋值 | `a[i:j]` / `a[i:j]=list` | 半开区间；越界错误明确 |
| `kh/kl` 用于数组 | `a.kh(n)`, `a.kl(n)` | 保留**能力**，数组后缀语法改为方法 |
| `.sum/len/shuffle/rand/randSize/push/pop/shift` | 同等 List API | 突变与返回值明确 |
| 字典、属性/下标读取 | Object / `.a` / `["a"]` | 对象键只允许 String；不隐式数字转 String |
| `.keys/.values/.items/.has/.get/.getRaw` | Object API；直接读取即原始字段 | 不再需要 `.getRaw()` |
| computed `&(expr)` 和 `&a` | `formula(ctx => expr)` + `.eval(ctx)` | **语义不兼容**；显式执行 |
| `loadRaw*` | 直接读取 Formula 对象、`obj.get()` | 去除隐藏计算产生的双读取路径 |
| 字典/函数的 `this` | `self`（方法）、普通参数/闭包 | 不继承其绑定和捕获的隐式特性 |
| 函数声明、递归、函数作为值 | 命名函数、lambda、对象方法 | 不使用 `func` 关键字 |
| `if/else`, `while`, `return`, `break`, `continue` | 保留全部控制能力 | 引入词法作用域与表达式化 if |
| 条件表达式 `? :` | 保留 | 条件必须 Bool |
| `??` 空值合并 | 保留 | 只合并 null，不合并 false/0 |
| `+ - * / %`, 比较, `& |`, `^/**` | 覆盖并定义明确优先级 | 运算类型与溢出行为有变化 |
| `&&/||` 返回操作数 | Bool 短路逻辑 | **语义不兼容**；需要旧脚本改写 |
| 模板字符串、模板内复杂逻辑 | 反引号 `{expr}` + 外部 `{{script}}` | 旧 `{%...%}` / `\x1e` 不直接继承 |
| 末表达式输出 | 执行块值替换 | `null`/Unit/空串不插入，`0`/false 插入 |
| 全类型序列化（含函数） | 原生值/闭包/对象图/Formula/Roll 序列化 | 宿主 native 类型须有可恢复适配器 |
| 计算细节显示 | `Roll.detail`, `Roll.trace` | 结构化过程优先，不仅是字符串 |
| 角色卡属性与宿主变量 | 宿主 `actor` / `state` 等对象 | 不再默认全局变量可随意赋值 |
| 解释器算力上限 | 统一执行预算 | 精确执行限额由宿主设定 |
| 关闭逻辑语句 | 纯骰点表达式模式 | 不能改变普通词法解释 |
| 开关 CoC/WoD/Fate/DX 的宏 | 宿主规则许可与 r 字面量 | 不再通过注释宏重写文法 |
| `floor/ceil/round/abs/int/float/str/bool/repr/dir/typeId/load` | 数学/转换/反射最小集 + 受限 host 变量接口 | `load` 动态查名改由宿主环境对象；不保证逐函数同名 |

## 兼容性准则

1. **能力覆盖优先**：只要普通用户可通过新语法实现等效规则计算，即视为设计层面覆盖；不能据此宣称源码完全兼容。
2. **行为变化显式列出**：computed 自动求值、隐式全局变量、规则骰与标识符重叠、真值转换、`this`、字符串键转换、逻辑运算返回操作数等，均刻意不保留。
3. **旧脚本迁移不是本草案内容**：本文只说明语义映射，不设计开发计划、迁移工具或实现步骤。

## 尚需精确核对的细节

- 各规则骰的全部别名、默认参数及修饰符与 DiceScript 最新具体版本的精确等价关系。
- Double Cross 与 WoD 的参数签名和计算轨迹表示。
- DiceScript 内建函数的非主流调用惯例与边界行为。

以上差异不应被误写为“已验证 100% 语义一致”；请参阅 `08-open-questions.md`。
