# 06 · 静态诊断与错误语义

> 本文规定错误的**语言体验和结构化信息**，不声称已有对应检查器。

## 诊断的数据契约

每个诊断至少包含：稳定的 `code`、错误级别、用户可读短消息、UTF-8 源码的起止偏移及行列号、相关位置（如声明处）、可选修复建议。行列号采用 1 起始、以 Unicode 标量值计列；宿主可转换为 LSP 所需的 UTF-16 偏移。

语法错误发生时，分析器应恢复到下一可识别的语句或对象成员分隔符，继续报告后续错误。错误恢复不能悄悄改动代码解释。

| 代码 | 类别 | 举例 |
|---|---|---|
| `S001` | 词法错误 | 未闭合的 `"` / 反引号模板 |
| `S002` | 语法错误 | 对象成员少 `,`、多余 `}` |
| `N001` | 未声明名称 | `力星 = 70`，但声明了 `力量` |
| `N002` | 重复声明 | 同一词法作用域出现两次 `x :=` |
| `T001` | 不兼容类型 | `hp := 12; hp = "12"` |
| `T002` | 条件并非 Bool | `if 1 { ... }` |
| `C001` | 调用参数不合法 | `abs()`、`Int("abc")` 的静态/运行检查 |
| `O001` | 字段不存在 | `r.hp`，而静态已知只有 `HP` |
| `D001` | 骰点语法错误 | `3d0`、无效修饰符 |
| `D002` | 骰点配置不允许 | 已知宿主禁用了指定规则骰 |
| `F001` | 公式效果违规 | `formula(ctx => state.x = 1)` |
| `R001` | 运行资源耗尽 | 无限循环、过多骰子或爆骰轮次 |
| `P001` | 序列化失败 | 捕获了没有适配器的宿主原生对象 |
| `H001` | 渲染失败 | `to_text()` 有副作用/返回非 String |

## 错误报告示例

```text
1 | 力量 := 60
2 | 力星 = 70
    ^^^^
N001: 未声明的变量「力星」
  建议：你是否想使用第 1 行声明的「力量」？
```

```text
1 | r := { HP: 10, heal(n) { self.HP = self.HP + n; self.HP } }
2 | r.HP = "很多"
         ^^^^^^
T001: 不能将 String 赋给已知类型为 Int 的字段 HP
  建议：使用明确转换，或将字段声明为动态值。
```

```text
1 | 3d6kh9
    ^^^^^^^
D001: 保留的骰子数量 9 超过总骰数 3
```

`r"b2"` 即使成功解析，也应把规则来源与参数位置写入 Roll.trace；运行时错误同样返回源码定位。某一处出现运行错误时，解释器不得改成空字符串继续假装成功。

## 分析器应能识别什么

必须能静态识别：括号/字符串/模板闭合问题、已声明名字、基本参数个数、常量骰点非法范围、确定可知的类型冲突、常量字段不存在、纯表达式模式下的写操作。无法获知的宿主字段与 Any 动态值，保留运行时检查，不制造虚假的静态安全感。

对代码高亮/编辑器支持的要求属于**规范可分析性**，不是开发日程：关键字集合固定、主语言骰点词法不依赖临时的规则宏、对象方法与函数声明有明确的文法边界，错误恢复不导致其他合法代码失去着色。
