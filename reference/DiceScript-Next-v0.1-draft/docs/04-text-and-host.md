# 04 · 文本嵌入、渲染、宿主数据与序列化

## 执行块与渲染边界

文本执行块的形式暂定为 `{{ script }}`。它在**宿主文本**里标记一段完整脚本，不属于普通字符串。脚本最后一个表达式的值即执行块的返回值。

```text
调查员侦查：{{ 骰 := d100; if 骰 <= actor.侦查 { `成功 {骰.total}` } else { `失败 {骰.total}` } }}
```

宿主按文本顺序执行多个块，依照当前环境和随机源。扫描 `{{...}}` 时必须理解嵌套的 `{}`、引号、转义，不能简单用正则匹配第一个 `}}`（对象字面量或分支块本身可能含 `}`）。两个执行块之间共享哪些持久变量由宿主环境决定；块内 `:=` 的局部绑定不会自动成为下一块的全局变量。

返回值转换：

| 值 | 文字插入 |
|---|---|
| `Int(0)` / `Float(0)` | `0` / `0.0` 的标准文本 |
| `false` | `false` |
| `"hello"` | `hello` |
| `""` | 不插入任何文本 |
| `null`, `Unit` | 不插入任何文本 |
| `Roll` | 默认按总值展示（可通过 `.detail` 主动显示过程） |
| List / Object | 使用其默认的稳定显示形式 |
| 自定义有 `to_text()` 的对象 | 使用 `to_text()` 的返回 String |

`to_text()` 只能进行确定性无副作用计算；不可掷骰、修改状态或调用有外部效果的方法。它只在显式渲染边界被调用，普通对象读取、比较或赋值不会触发。若渲染抛出错误、结果不可渲染，宿主应报告诊断并按策略保留原执行块或标记错误，**不得悄悄视作 null**。

## 字符串插值

```text
名字 := "艾琳"
文本 := `角色 {名字}：体力 {actor.HP}`
```

仅反引号字符串支持 `{expr}`；普通 `'...'` 与 `"..."` 是原样文本（仅处理转义）。插值内容是普通表达式，不能在 `{...}` 中声明变量或执行多条语句；复杂逻辑应该在外部执行块或先调用函数。文字 `{` 使用 `{{` 转义，文字 `}` 使用 `}}` 转义（**仅模板字符串内部**）。插值渲染采用与外部执行块相同的值转换规则。

为避免「外层执行块 `{{...}}` 与模板中的 `{{`」混淆，宿主先对源文本的执行块做词法级扫描，执行块中的反引号字符串由脚本词法器解析，二者的扫描上下文独立。

## 宿主对象（不是保留字）

宿主可以提供以下**约定命名**的对象：

- `actor`：当前人物卡，包含属性、字段以及由宿主暴露的可调用方法。
- `state`：用户/角色/会话范围的持久状态字典；读写必须尊重宿主权限。
- `coc`、`fate`、`wod`、`dx`：标准规则骰函数对象。启用哪些规则由宿主策略决定。
- 可选其他安全的本地原生对象；不允许语言脚本自行访问 JS 全局、文件、网络。

动态角色属性可以通过 `actor.get("力量", 0)` 获取有默认值的字段；直接读取 `actor.力量` 若不存在则报属性不存在，而不安静返回 null。宿主可提供属性名补全和类型元信息用于诊断，且必须避免将隐藏敏感字段误暴露在对象遍历中。

## 执行模式

同一语法提供不同宿主权限配置：

- **完整规则模式**：允许普通函数、对象与限额内的循环、对允许写的状态赋值。
- **纯骰点模式**：仅允许求值安全的算术/骰点/纯方法；禁止声明、赋值、`while`、持久化写入及非纯宿主调用。

这是一套**执行许可**，不是通过宏动态改变词法结果的语法开关。禁止的功能需要明确报诊断。

## 序列化契约

可持久化的脚本值包括 `Null`、`Bool`、`Int`、`Float`、`String`、`List`、`Object`、`Roll`、`Formula`、脚本 `Function` 和已绑定接收者的方法值。编码需要保存值类型、对象引用身份、别名、可能的循环引用、函数体/自由变量、Formula 绑定值、Roll 结构化轨迹，并包含独立的格式版本。

- 对脚本原生对象的序列化/反序列化不应调用 `to_text()`、对象方法或公式 `.eval()`。
- 对 `Roll` 的保存不得重新抽样；对 `Formula` 的恢复不得提前求值。
- 对象引用可成图，编码采用带身份标记的引用图格式；恢复时保留共享引用与循环引用。
- 宿主 NativeObject / NativeFunction 需要明确可恢复的**宿主注册标识 + 适配器**；没有适配器时报告“不可序列化的宿主对象”，而非伪造数据。
- 持久化函数必须保留其静态语义版本，不默默用后来不同的语法解释旧函数；不兼容版本时应报迁移错误。

## 副作用与预算

读取普通属性不执行 Formula；`get`/`has` 无随机副作用；显式 `.eval`/骰点表达式/随机集合方法才消耗随机源。运行时依据宿主预算计费，预算超限是诊断，不是 `null`。文件系统、网络访问、定时器、异步等不在脚本语言标准能力内；复杂插件由 JS 承担。
