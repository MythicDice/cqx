# 01 · 词法、语法、优先级

## 字符与注释

源代码按 UTF-8 解释。标识符支持 Unicode XID_Start / XID_Continue 及下划线，不允许以数字开头；`角色`、`hp_max` 合法，`3d6` 进入骰点词法而不是标识符。标识符中的冒号不是名字的一部分。大小写敏感，建议 Unicode 规范化采用 NFC；对仅规范化不同的标识符给出警告。

`#` 开始至行末为注释；字符串中的 `#` 无特殊意义。该草案不引入 DiceScript 的注释型语法开关。反斜杠转义用于字符串；单引号、双引号均为普通字符串，反引号为插值模板字符串。`r"..."` 为**骰点规则字面量**，不是原始字符串前缀。

## 换行与语句终止

- 顶层、控制流块、函数块内部：换行或 `;` 分隔语句；可多行写一个未完成的表达式。
- 圆括号、方括号内部的换行视为空白；对象字面量**成员必须以逗号**分隔，末尾逗号允许。
- 连续完整表达式不得仅靠空格分隔。`a := 1 b := 2` 是语法错误。
- `:=` 是唯一的声明操作符。`x: Int := 1` 为可选标注的声明。`x: Int = 1` 不合法。
- `=` 只对已存在的变量、可赋值的字段、合法的列表索引/切片赋值。声明和赋值语句返回 `Unit`。

## 语句与表达式

`if` 是表达式，`if true { 1 } else { 2 }` 得到 `1`。省略 `else` 且条件不满足时结果为 `Unit`。每个块取其**最后一个表达式**的值，末尾若只有声明/赋值/循环，则结果为 `Unit`。

`while condition { ... }` 是语句，结果为 `Unit`。`break`、`continue` 仅用于循环；`return` 退出最近函数，若直接处于宿主执行块顶层，则退出该执行块。

命名函数声明：

```text
加值(x, y: Int) -> Int { x + y }
```

参数注解和返回注解均可选；表达式形式的匿名函数：`x => x + 1`，多参：`(x, y) => x + y`；多语句函数可写 `(x, y) => { ... }`。匿名函数的参数不带括号时只能有一个参数。

对象字面量的成员只有两种形式：`key: expr` 和 `method(args) { ... }`，以逗号分隔；`method(args) -> Type { ... }` 可选返回注解。

```text
对象 := {
    HP: 12,
    受伤(n) { self.HP = self.HP - n; self.HP },
}
```

对象字面量 `{ ... }` 与流程块 `{ ... }` 由上下文区分：`:=` 后是表达式语境，`if/while/函数` 后是块语境。需要在块中返回对象时，写 `if ok { { x: 1 } }`。

## 骰点词法的安全边界

- `d20`、`3d6`、`2d20kh1` 等精确匹配基础骰点模式；`d20foo` 是普通标识符，不会被拆开悄悄执行。
- `(n + 1)d(20)`、`n d 6` 使用明确的 `d` 中缀运算符；表达式两端若不是裸数词，应允许空格或括号区分。
- `r"..."` 内部由选中的骰点子文法解释，诸如 `a2`、`b2` 等普通标识符不被主语言抢占。
- 自定义骰点规则只注册在 `r"..."`、`roll("...")` 的骰点语法空间；不得改变主语言的标识符解析。

## 运算符优先级（高 → 低）

| 等级 | 语法 | 结合规则 | 含义 |
|---|---|---|---|
| 1 | `a.b`, `a[b]`, `a(...)`, `a[b:c]` | 左 | 成员、调用、下标、切片 |
| 2 | 直接骰点 `NdM` 与 `kh/kl/dh/dl/min/max` 后缀；中缀 `d` | 左 | 创建 Roll |
| 3 | `**`、`^` | 右 | 乘方，`^` 是兼容别名 |
| 4 | 单目 `+ - ! ~` | 右 | 正负、逻辑否、按位取反 |
| 5 | `* / %` | 左 | 乘除模 |
| 6 | `+ -` | 左 | 加减、同类串/列表连接 |
| 7 | `<< >>` | 左 | 整数位移 |
| 8 | `< <= > >=` | 不可链式 | 比较 |
| 9 | `== !=` | 不可链式 | 相等比较 |
| 10 | `&` | 左 | 按位与 |
| 11 | `|` | 左 | 按位或 |
| 12 | `&&` | 左 | Bool 短路与 |
| 13 | `||` | 左 | Bool 短路或 |
| 14 | `??` | 右 | Null 合并 |
| 15 | `cond ? yes : no` | 右 | 三目表达式 |

赋值、声明不属于表达式优先级表。分隔符 `:` 在 `x: Int := ...`、对象成员、具名参数及三目运算中分别由语法位置确定。为避免歧义，范围 `[a..b]` 是特殊的列表构造形式，不把 `..` 作为通用中缀运算符。

**设计决定**：位移运算仅作用于 Int；由于 `^` 已作为乘方别名保留，不另设 XOR 符号，若需要 XOR 可用内建 `bitXor(a,b)`。

## 类型标注

`Int`、`Float`、`Bool`、`String`、`Roll`、`Formula`、`List`、`Object`、`Any`、`Int?` 等为可使用的类型表达式；参数、局部变量、返回值均可省略标注。v0.1 不引入泛型书写语法，不用 `List<Int>` 强迫用户声明集合元素类型；分析器可内部推断。
